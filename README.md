## 🛠 기술 결정

- **No build step** — HTML/CSS/JS만으로 GitHub Pages에 즉시 배포
- **Mermaid.js (CDN)** — 아키텍처 다이어그램을 코드로 관리
- **Inter + Noto Sans KR + JetBrains Mono** — 영문/한글/코드 균형
- **CSS Custom Properties** — 색상·간격 토큰 일원화
- **IntersectionObserver** — 가벼운 진입 애니메이션 + nav 활성 섹션
- **Print-friendly CSS** — 인쇄 시 nav·hero 배경 제거
